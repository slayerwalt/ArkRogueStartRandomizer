# 黑流树海开局随机器 — 设计文档（v2）

- 日期：2026-08-20
- 状态：v2，加入「希望」硬约束，与用户确认中

## 1. 目标

做一个明日方舟集成战略「沉沦者的黑流树海」开局随机器：随机开局分队与招募组合，并按「希望」约束随机每个券位的具体干员。形态是无需后端的网页。

v2 相比 v1 的核心变化：**引入「希望」资源约束**，保证随机出的开局在游戏内是合法可达的（不会出现「开局三个六星」这种希望不够的组合），并纳入分队招募减免与机械师特殊减免。

## 2. 范围

### 做

- 随机**分队**（15 个基础分队）
- 随机**招募组合**（6 个开局组合）
- 按**希望硬约束**随机每个券位的具体干员：总希望消耗不超过初始希望
- 「尽量高星」：每个券位在当前剩余希望内优先选最高星干员
- 分队招募减免（职业/子职业）、后勤分队初始希望加成
- 机械师特殊减免（天赋精通满级）
- 手动排除指定干员
- 单项重摇（分队、每个券位）
- 设置持久化（排除名单）

### 不做（本版明确排除）

- 星级筛选（改为自动「尽量高星」）
- 1-2 星干员（不纳入随机池）
- 预备干员、临时招募干员（Sharp/Pith/Touch/Stormeye/Mechanist 等）、盟约干员（均不纳入随机池）
- 保密等级（难度）选择（开局是初始招募，难度加成只影响后续招募）
- 图片素材、按用户 box 过滤、后端、历代主题数据
- 机械师的精通等级选择（默认满级）

## 3. 希望系统规则

### 3.1 初始希望

开局初始希望 **6 点**。后勤分队效果「初始希望 +2」→ 该分队下初始希望为 8。

### 3.2 招募希望消耗（开局初始招募）

黑流树海开局有「初始招募 −1 希望」的全局减免，因此：

| 星级 | 消耗（开局） |
|---|---|
| 六星 | 6 |
| 五星 | 2 |
| 四星 | 0 |
| 三星及以下 | 0 |

（说明：N15 下非初始招募为六星 7、五星 3；开局 −1 得六星 6、五星 2。四星及以下本为 0。）

### 3.3 分队招募减免

以下分队在开局随机时对「4 星及以上」的干员生效（均为招募 −2 希望，数据来源 `relics.*.buffs[recruit_cost]`）：

| 分队 | 减免对象 |
|---|---|
| 突击战术分队 | 近卫、先锋 |
| 堡垒战术分队 | 重装、辅助 |
| 远程战术分队 | 医疗、狙击 |
| 破坏战术分队 | 术师、特种 |
| 高台突破分队 | 术师、狙击、医疗、辅助 |
| 地面突破分队 | 先锋、近卫、重装、特种 |
| 本源研修分队 | 本源术师、本源铁卫、本源近卫、巫役（按**子职业**，`recruit_cost_sub_profession`） |

分队减免与干员自身减免（如机械师）**可叠加**。

### 3.4 机械师特殊规则

机械师（`char_4230_mcnist`，六星重装）拥有「精通」系统，满级招募减免 **−4**：

- 正常（不选堡垒/地面突破分队）：六星 6 − 4 = **2 希望**
- 选堡垒战术或地面突破分队（重装 −2）：2 − 2 = **0 希望**（免费）

## 4. 干员池

### 4.1 范围

- 仅保留 **3-6 星**干员（1-2 星不纳入）
- 仅保留常规可获得干员（`isNotObtainable === false`）
- 排除：TOKEN（召唤物）、TRAP（陷阱）、预备干员、临时招募干员（Sharp/Pith/Touch/Stormeye/Mechanist 等 15 位）、盟约干员（1 位）

### 4.2 每名干员需要的新字段

- `subProfessionId`（子职业，用于本源研修分队减免判断）
- 常规干员已有 `rarity`、`profession`、`name`、`id`

## 6. 随机算法（硬约束 + 尽量高星）

1. **随机分队**：从 15 个基础分队均匀随机。
2. **计算初始希望**：6 + 分队 `initialHopeBonus`。
3. **随机招募组合**：从 6 个开局组合均匀随机，得到券位列表（每个券位含职业范围、rarityCap）。
4. **随机打乱券位顺序，按随机顺序逐个券位随机干员**（不让高星干员总固定在某一个券位）：
   - 候选 = 满足「职业在该券位允许范围内 ∧ 3-6 星 ∧ 未排除」的干员。
   - 对每个候选计算**实际希望消耗** = `hopeCost` + 分队减免（若符合职业/子职业且 ≥4 星）+ `charDiscount`（机械师 −4），下限为 0。
   - 过滤出「实际消耗 ≤ 剩余希望」的干员。
   - 在过滤结果中取**最高星级**一档，从该档随机一名干员。
   - 扣除实际消耗，更新剩余希望。
5. **空池处理**：若某券位过滤后为空（排除名单导致连 0 希望干员都没有），该券位标记「无可选干员，请调整排除名单」，其余券位正常。

「重摇」逻辑：分队重摇 → 重新随机分队并重算初始希望，券位全部重新随机；单个券位重摇 → 仅该券位在当前状态下重新随机（使用重摇前的初始希望减去其余券位的消耗作为预算）。

## 7. 数据提取脚本改动

- `extractOperators`：过滤改为「8 大职业 ∧ 非 TOKEN/TRAP ∧ `isNotObtainable === false` ∧ rarity ∈ [2,5]（即 3-6 星）」。预备干员、临时招募干员（Sharp/Pith/Touch/Stormeye/Mechanist/Raidian/Misery/郁金香/暮落 等）、盟约干员均不纳入。新增 `subProfession`、`hopeCost`、`charDiscount` 字段。
- `extractSquads`：新增 `initialHopeBonus`（后勤 +2）与 `recruitDiscount`（解析 `relics.rogue_6_band_*.buffs[recruit_cost]`/`recruit_cost_sub_profession`）。
- 建立子职业中文名映射与机械师减免常量。

## 8. 错误处理

- 数据缺失/格式非法：页面显示中文错误，不白屏（沿用 v1）。
- 某券位候选池为空：显示「无可选干员」提示，不崩溃。
- 排除名单含已删除干员：加载时剔除并回写（沿用 v1）。
